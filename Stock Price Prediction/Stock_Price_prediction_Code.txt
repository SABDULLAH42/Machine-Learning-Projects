MinMaxScaler is a Scikit-learn tool that changes the scale of numerical data.

Your POWERGRID prices could look like:

A neural network such as an LSTM generally works better when the input values are on a smaller, consistent scale.

So we transform the values into a range between:

0 and 1

2. Create the scaler
scaler = MinMaxScaler(feature_range=(0, 1))

This tells Scikit-learn:

"When I scale my data, convert it to a range from 0 to 1."

For example, imagine the minimum price is:

₹20

and the maximum price is:

₹100

The scaler transforms them approximately like this:

Original price	Scaled value
₹20	0.00
₹40	0.25
₹60	0.50
₹80	0.75
₹100	1.00

So instead of the model seeing:

20, 40, 60, 80, 100

it sees:

0, 0.25, 0.50, 0.75, 1.0

3. How does MinMaxScaler calculate this?

The basic idea is:

Scaled Value =
(Current Value - Minimum Value)
--------------------------------
(Maximum Value - Minimum Value)

4. Very important: creating the scaler does NOT scale your data

This line:

scaler = MinMaxScaler(feature_range=(0, 1))

only creates the scaler object.

Your data hasn't changed yet.

You need to use:

scaler.fit_transform(...)

For your training data, you'll typically see:

data_training_scaled = scaler.fit_transform(data_training)

fit

The scaler learns:

Minimum training price
Maximum training price

transform

It then converts the training prices into the 0 to 1 range.

So:

scaler.fit_transform(data_training)

means:

Learn the minimum and maximum from the training data, then scale the training data using those values.

5. Why should we fit only on training data?

This is very important for your stock prediction project.

You should do:

data_training_scaled = scaler.fit_transform(data_training)

and not:

scaler.fit_transform(df)

Why?

Because your testing data represents the future.

If the scaler learns the minimum and maximum from your testing data, information from the future can leak into your training process.

That's called data leakage.

The correct approach is:

Training data
     ↓
scaler.fit()
     ↓
Learn min/max
     ↓
scaler.transform(training)
     ↓
Training scaled

Then:

Testing data
     ↓
scaler.transform(testing)
     ↓
Testing scaled

Notice that we don't fit the scaler again on testing data.
